# RetireWise — 退休自由試算器

RetireWise 是公開版退休/FI 試算工具。使用者手動輸入自己的資產、儲蓄、生活費、報酬率與通膨假設，即時比較退休規劃結果。

公開版重點：

- 不需要登入。
- 不上傳使用者資料。
- 儲存情境只存在使用者自己的瀏覽器 `localStorage`。
- 可輸出成靜態網站，部署到 GitHub Pages 或 Firebase Hosting。

## Public Web App

### 安裝

```bash
npm install
```

### 本機開發

```bash
npm run dev
```

啟動後開啟 `http://localhost:3000`。

### 測試

```bash
npm test
```

目前測試涵蓋退休計算核心與 localStorage 情境儲存。

### 靜態建置

```bash
npm run build
```

Next.js 設定為 `output: 'export'`，建置完成後會產生 `out/`，可部署到靜態主機。

## 部署

### GitHub Pages

建議使用 GitHub Actions 執行：

```bash
npm install
npm run build
```

再將 `out/` 發佈到 GitHub Pages。

### Firebase Hosting

若之後想銜接 Firebase Hosting，也可以直接把 `out/` 作為 public directory。Phase 1 不需要 Firebase Auth 或 Firestore。

## 功能

- 指定月花費模式：設定退休後目標月花費，估算 FI 年份、退休年齡、所需資產、缺口與進度。
- 壽命規劃模式：設定預期壽命與死亡時目標剩餘，逆推可支撐的最大月花費。
- 雙模式資產曲線：比較退休後資產走勢。
- 逐年明細：列出年花費、投資報酬、年末資產與是否耗盡。
- 情境儲存：儲存、套用、刪除瀏覽器本機情境。
- 早存複利比較：設定前期加速年數與每月多存金額，比較原方案與加速方案的 FI 年、耗盡年與壽命終點資產差額。
- 歷史市場壓力測試：以 1926-2025 年美國大型股年總報酬的滾動序列，顯示歷史存活率、典型耗盡年齡與 90% 情境所需資產，檢視退休後的報酬順序風險。

## 輸入參數

| 參數 | 說明 |
|------|------|
| 目前資產 | 目前可投資資產或淨值，作為試算起點 |
| 退休前每月投入 | 退休前每月固定投入金額，用於資產累積 |
| 每月目標生活費 | 退休後每月期望花費（今日幣值） |
| 退休前年化報酬率 | 退休前投資預期年化報酬 |
| 退休後年化報酬率 | 退休後保守配置預期報酬 |
| 通膨率 | 生活費每年通膨幅度 |
| 目前年齡 / 預期壽命 | 用於換算退休年齡與試算終點 |
| 安全提領率 | 保留為參考輸入 |
| 死亡時目標剩餘 | 希望壽命終點仍保留的資產 |

## 計算邏輯

- 退休前資產用目前資產、退休前每月投入與年化報酬率逐年累積。
- 指定月花費模式用二分搜尋找出退休後模擬到壽命終點仍可維持的最低退休本金。
- 壽命規劃模式用現值分母法，在指定報酬率、通膨與死亡剩餘下逆推最大月花費。
- 表格顯示值會將負資產歸零，避免呈現不具實務意義的負數餘額。
- 壓力測試保留使用者設定的退休後平均報酬率，並加入歷史年報酬相對長期平均的偏離，避免將美股報酬直接誤當成每個人的投資組合報酬。

## Legacy Streamlit App

舊版 Streamlit app 仍保留在 `app.py`，可作為計算邏輯參考或本機原型使用。

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py
```

公開部署建議使用 Next.js 靜態版，而不是 Streamlit 版。
