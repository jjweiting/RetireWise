# 🏖️ RetireWise — 退休規劃試算工具

獨立的退休規劃 Streamlit App，從個人資產管理系統的「退休規劃」分頁獨立出來。

## 功能

- **📅 指定月花費模式**：設定目標月花費 → 自動計算財務自由 (FI) 年份與所需本金（退休後資產持續正成長，永不歸零）
- **💀 壽命規劃模式**：設定壽命目標 → 逆推退休後每月最大可用花費（資產到壽命剛好燒完）
- **雙模式並排比較圖表**：兩條資產曲線統一到壽命終點，方便直觀比較
- **逐年明細表格**：每年花費、投資報酬、年末資產一覽無遺
- **📄 PDF 報告下載**：一鍵產生完整退休規劃報告（含參數摘要 + 逐年明細）
- **💾 計劃儲存與比較**：儲存多個情境，橫向比較找出最佳策略

## 快速開始

```bash
# 安裝依賴
pip install -r requirements.txt

# 啟動 App
streamlit run app.py
```

## 輸入參數說明

| 參數 | 說明 |
|------|------|
| 目前資產 | 目前可投資資產或淨值，作為試算起點 |
| 每月儲蓄 | 每月固定投入金額，用於退休前資產累積 |
| 每月目標生活費 | 退休後每月期望花費（今日幣值） |
| 退休前年化報酬率 | 退休前投資預期年化報酬，預設 7% |
| 退休後年化報酬率 | 退休後保守配置預期報酬，預設 5% |
| 通膨率 | 生活費每年通膨幅度，預設 3% |
| 目前年齡 / 預期壽命 | 用於換算退休年齡與試算終點 |
| 安全提領率（📅 專屬）| 4% 法則，決定 FI 門檻高低 |
| 死亡目標剩餘（💀 專屬）| 希望留下的遺產金額，填 0 = 剛好燒完 |

## 計算邏輯

- **📅 FI 門檻**：用二分搜尋法找出「退休後模擬到壽命，最終資產 ≥ 起始資產」的最低退休本金
- **💀 逆推月花費**：年金現值公式逆推，在既定報酬率與通膨下，退休到壽命剛好花完的最大月支出
- 兩條曲線 X 軸統一到壽命年份，方便並排比較

## 依賴套件

- `streamlit` — UI 框架
- `plotly` — 互動圖表
- `pandas` — 資料處理
- `weasyprint` — PDF 報告產生
